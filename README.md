# 王恩涛｜视效知识库

基于 React + Vite 的 AE 插件、脚本与制作经验知识库。内容整理自公开 Notion 页面，包含检索、分类筛选、案例图和条目详情。

`public/assets/knowledge` 中保存了从原始 Notion 页面整理的 90 张条目案例图，网站部署后不依赖 Notion 的临时图片地址。

## 本地运行

```bash
pnpm install
pnpm dev
```

## 构建

```bash
pnpm build
```

仓库包含 GitHub Pages 工作流。将 Pages 的发布来源设为 GitHub Actions，推送到 `main` 分支后即可自动部署。
